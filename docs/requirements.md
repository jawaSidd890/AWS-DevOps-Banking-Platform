Project Objective:
Build and operate a secure, scalable banking application on AWS using DevOps best practices.

Functional Requirements:
- Application should be containerized
- Application should run on Kubernetes (EKS)
- CI/CD pipeline must automate build and deployment
- Infrastructure must be created using Terraform
- Monitoring and logging must be enabled
- Security scanning must be part of the pipeline

Non-Functional Requirements:
- High availability
- Automated rollback on failure
- Secure access using IAM
- Production-grade observability
